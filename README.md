# Los Simpson

App Android (Kotlin + Jetpack Compose) para celular, TV box y Google TV.

## Funciones
- Abre directo la pantalla para elegir temporada y capítulo.
- Navegador integrado con pantalla completa para el video.
- Control remoto: las flechas saltan entre temporadas y capítulos (borde amarillo) y OK selecciona.
  Al entrar al reproductor se activa un cursor para usar los controles del video.
- Bloqueo de anuncios, popups y redirecciones (`AdBlocker.kt`) y panel 🛡 para bloquear o permitir sitios.
- Se cierra por completo al salir (nada en segundo plano).

## Compilar
Android Studio, o con GitHub Actions (`.github/workflows/build.yml`).
